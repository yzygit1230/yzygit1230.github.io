# GitHub 个人主页模板

这是一个轻量静态个人主页，风格参考简洁的学术主页：简介、动态、项目、论文、经历和学术活动集中在一个页面里。

## 使用方式

1. 把仓库命名为 `你的GitHub用户名.github.io`。
2. 修改 `index.html` 里的姓名、简介、链接、论文、项目和经历。
3. 用真实头像替换 `assets/avatar-placeholder.svg`，并在 `index.html` 中更新图片路径。
4. 推送到 GitHub 后，在仓库 `Settings -> Pages` 中选择从默认分支发布。

本地预览可以直接双击打开 `index.html`。
